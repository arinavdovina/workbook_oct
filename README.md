# Тетра — конструктор рабочих тетрадей

Статическое веб-приложение на русском языке для преподавателей иностранных языков. Помогает собрать подробный промпт для создания рабочей тетради в ChatGPT или другом ИИ.

## Возможности

- Любой изучаемый язык, уровни A1–C2, возрастная группа и особенности обучения.
- Тема урока, ключевая лексика, грамматика и исходные материалы.
- 180 механик: по 30 для чтения, аудирования, говорения, письма, лексики и грамматики.
- Рекомендации по уровням, поиск, автоподбор, ручной выбор и изменение порядка упражнений.
- Три формата: печатная тетрадь, страницы-картинки и интерактивный HTML.
- Для картинок: 8, 9 или 10 отдельных страниц, последовательная генерация без коллажей.
- 8 вариантов дизайна с условными превью, сочетание стилей и собственное описание.
- 20 готовых промптов и случайный выбор.
- Ключи, критерии оценивания, рефлексия, домашнее задание и языковые опоры.
- Автосохранение в браузере, импорт/экспорт проекта JSON, экспорт промпта TXT и плана Markdown.

## Что именно делает приложение

Конструктор создаёт **промпты**, а не обращается к модели напрямую. Скопируйте итоговый промпт в выбранный ИИ для получения текста, изображений или HTML-кода тетради. API-ключи, сервер и платные зависимости не требуются.

В режиме картинок промпт требует отдельные последовательные изображения. Возможность выполнить всю серию без остановки зависит от инструмента генерации и его лимитов. Предусмотрена команда продолжения со следующей страницы.

В HTML-режиме промпт задаёт автопроверку закрытых заданий. Свободная речь, письмо и творческие ответы проверяются по рубрике преподавателем или самим учеником.

## Быстрый запуск

Распакуйте архив и откройте `index.html` в браузере. Для стабильной работы буфера обмена и браузерного хранилища предпочтительнее локальный HTTP-сервер:

```sh
cd tetra-workbook-studio
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для остановки сервера нажмите Ctrl+C.

Начните с кнопки «Заполнить пример» или раздела «20 промптов».

## Загрузка в GitHub

1. Создайте пустой репозиторий в своём аккаунте GitHub.
2. Распакуйте ZIP и загрузите **содержимое** папки `tetra-workbook-studio` в корень репозитория. `index.html` должен лежать непосредственно в корне, а не внутри дополнительной папки.
3. Сохраните изменения в ветке `main`. Сам ZIP загружать вместо файлов не нужно.

Если используете Git локально:

```sh
cd tetra-workbook-studio
git init
git add .
git commit -m "Add Tetra workbook prompt constructor"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

Замените `YOUR_USERNAME` и `YOUR_REPOSITORY` своими значениями. В архиве нет привязки к чужому репозиторию, истории Git или служебного доступа к хостингу.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите публикацию из ветки (**Deploy from a branch**), ветку `main` и папку `/ (root)`. Сохраните настройки и дождитесь адреса сайта в разделе Pages.

Сборка не требуется: все пути к CSS и JavaScript относительные, поэтому приложение подходит и для сайта репозитория в подпапке. Доступность Pages зависит от настроек и типа репозитория. Этот архив не переносит приватную авторизацию прежнего хостинга: доступ к опубликованному сайту определяется настройками GitHub Pages.

## Проверки

Нужен Node.js 20 или новее. Установка npm-пакетов не требуется.

```sh
npm test
```

Проверяются синтаксис, число механик, охват уровней, три формата промптов, 20 примеров, сохранение выбранных упражнений при распределении на 8–10 страниц, передача дизайна и совместимость со старыми проектами. Это проверки данных и логики с упрощённой моделью DOM; они не заменяют визуальную проверку в браузере.

## Данные и внешние ресурсы

Черновик хранится в `localStorage` под ключом `tetra-v1` только в текущем браузере и на текущем адресе сайта. Для переноса между устройствами или адресами используйте экспорт/импорт JSON. Экспорт проекта может содержать введённые вами сведения — не добавляйте личные проекты учеников в публичный репозиторий.

Приложение не отправляет содержимое формы в ИИ и не использует аналитику. CSS загружает шрифты Golos Text и Manrope через Google Fonts; при отсутствии сети используются системные шрифты. Кнопка копирования может зависеть от разрешений браузера; скачивание TXT остаётся альтернативой.
